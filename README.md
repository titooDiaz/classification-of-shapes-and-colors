# Classification of Shapes and Colors

## Description

This project aims to develop a prototype of a conveyor belt system capable of automatically classifying objects based on their **shape and color**.

The system will simulate an industrial sorting process in which objects move along a conveyor belt and are identified using a camera and a computer vision model. Based on the detected characteristics, each object can be directed to a specific category.

## Objectives

- Detect and classify objects by shape: **triangle, cylinder, and cube**.
- Identify object colors: **green, blue, and red**.
- Integrate computer vision into a conveyor belt prototype.
- Demonstrate an automated object-sorting process inspired by industrial applications.

## Expected Result

A functional prototype that identifies objects as they travel along the conveyor belt, classifies them according to their shape and color, and provides the basis for an automated sorting mechanism.
